Usage-pattern clusters

Each active user is reduced to 16 features spanning six axis families — token intensity, session depth (tokens/request and 1h-vs-5m cache mix), cadence (days active), cache/output working style, product mix, and model tier (Opus / Sonnet / Haiku / Fable) — then grouped with k-means and projected to 2 dimensions for this plot. Model tier and session depth are what separate the coding archetypes: deep-Opus power coders, Sonnet-first everyday coders, and Opus+Fable high-throughput automation. Position has no literal unit; proximity is what matters — points near each other share a usage pattern. See the other tabs for volume, model, and product cuts, and “All users” for the raw table.
